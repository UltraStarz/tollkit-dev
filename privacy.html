Tollkit API privacy policy

For Tollkit’s paid tools: the HTTP API on api, web, data, chain and attest.tollkit.dev, and the MCP server at extract.tollkit.dev/mcp. Effective October 20, 2026. The Tollkit Wallet extension has its own policy.

In short: no accounts, no cookies, no analytics, no ads. What you send a tool is used to answer that call and isn’t saved. When you pay, we record which tool the payment was for, alongside the payment itself, which is already public on the blockchain. A few things are kept only when you ask us to, such as an alert you set up.

Who we are

Tollkit is made by Tollkit LLC, USA. Questions or requests: hello@tollkit.dev.

What you send a tool

Each tool takes an input: a web address, a search query, some text, a ticker, a wallet or token address, coordinates or a street address. We use it to answer that one call and don’t save it, with one exception: to tell price checks apart from real questions, we keep a short public label for some inputs, such as a website’s domain (not the full address), a stock ticker, a token contract, a currency pair, an airport code or a network name. Search queries, wallet addresses, IP addresses, street addresses and text you send are never kept, only counted.

When you pay

Payments are made in USDC with the x402 protocol. For each paid call we record the time, the tool, the network, the paying wallet address and the transaction ID. The payment itself is public on the Base or Solana blockchain. Our public stats page shows only counts, tools, networks and times, not wallets. A failed call isn’t charged.

Kept for a short time, in memory only

  • Request counts per minute and response times, for 24 hours, to show whether the service is healthy.
  • Free trial calls through MCP: a count per caller, keyed by IP address, reset each day.
  • If you send an Idempotency-Key header, that paid answer is kept for 10 minutes so a retry with the same key isn’t charged twice.

These are cleared when the server restarts and are never written to disk.

Kept only when you ask

  • Weigh Station monitoring: the endpoint you want watched, the web address for your alerts, and the wallet that signed up. Kept for the paid period.
  • Low-balance alerts: the public wallet addresses to watch and where to send the alert (a web address, an email, or both). Alert emails are sent through Resend. You can delete your alerts with a signature from the same wallet.
  • Market report emails: your email address, if you subscribe. We send nothing until you confirm it.
  • Page proofs (attest): not kept. You get the whole signed record; we keep only the key that signs it.

Outside services that receive your input

Some tools need another service to answer. Only what that call needs is sent, over HTTPS.

  • Web search: your search query goes to Serper (serper.dev), and to Tavily (tavily.com) if Serper is down.
  • Summaries and page briefs: the text to summarize goes to Anthropic’s API (Claude).
  • Reading pages, screenshots, PDFs and product data: our browser visits the web address you give, like any visitor.
  • Public data: tickers to the SEC (EDGAR); coordinates to the US National Weather Service or MET Norway; addresses to the US Census Bureau geocoder; airport codes to the FAA; currency codes to the European Central Bank. IP lookups use a database on our own server, so the address isn’t sent anywhere.
  • On-chain tools: wallet, token and transaction addresses go to public blockchain endpoints for Base, Ethereum and Solana.
  • Crypto market tools: crypto news queries go to Serper, and the headlines it returns go to Anthropic’s API (Claude) for the short read; coin names go to Hyperliquid’s public API; price history and the market pulse read Chainlink price feeds on Ethereum; the market pulse also reads the Fear & Greed Index from Alternative.me, which receives nothing from you.
  • Payments: the signed payment goes to Coinbase’s x402 facilitator, which settles it on the blockchain.

The server runs on Fly.io and this website on Cloudflare, which may keep standard connection logs under their own policies.

What we don’t do

  • No accounts, cookies, analytics, tracking or ads.
  • We don’t sell data or share it for advertising.
  • We don’t use your inputs to train AI models.

Your requests

To ask what we hold about a wallet address or email, or to have it deleted, write to hello@tollkit.dev. Payments on the blockchain can’t be deleted by anyone.

Changes

If this policy changes, the new version will be posted here with a new effective date.
