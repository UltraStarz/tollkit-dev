How paying works

  • 1. AskYour AI calls a tool. Without a payment it gets the price back, not an error.
  • 2. PayIt signs a USDC payment on Base or Solana from the wallet it was given. No ETH or SOL needed for fees.
  • 3. Get the resultThe call runs and settles. If it fails, nothing is charged. Each answer comes with a receipt, and a retry with the same Idempotency-Key isn’t charged twice.

Skills and plugin

The same tools, packaged so an agent knows when to use them. Source: github.com/UltraStarz/tollkit-skills.

Any agent that supports skills (Claude Code, Cursor, Codex and others):

npx skills add UltraStarz/tollkit-skills

Claude Code plugin (adds the skills and the MCP server): run /plugin marketplace add UltraStarz/tollkit-skills, then /plugin install tollkit@tollkit.

AgentCash: npx agentcash@latest add https://web.tollkit.dev (and the same for chain, data and extract).
